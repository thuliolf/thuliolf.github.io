Como trabalho

Práticas que se repetem em todas as entregas.

  • O sistema padrão fica intocado

    Todo objeto novo leva o prefixo AD_ e campos são criados pelo dicionário de dados. Atualizações do ERP não quebram nada.

  • Reprocessar é seguro

    Chaves de rastreio, pré-checagem, backup e script de rollback: rodar de novo nunca gera guia, nota ou comissão em dobro.

  • Conferido contra o que o usuário já confia

    Cada número novo é comparado com um relatório ou campo nativo que a equipe usa antes de ir para validação.

  • Primeiro o processo, depois o código

    Antes de customizar, confiro se o processo do ERP já resolve. Às vezes o erro está no lançamento, não na consulta.

  • Erro que se explica

    Quando falta cadastro ou não há o que processar, a mensagem diz o motivo e onde corrigir.

  • Decisão de negócio é do cliente

    Pontos em aberto viram lista de definições com proposta técnica, e cada entrega sai com documentação para quem opera.
