How I work

Practices that repeat across every delivery.

  • The standard system stays untouched

    Every new object carries the AD_ prefix and fields are created through the data dictionary. ERP updates break nothing.

  • Reruns are safe

    Tracking keys, pre-checks, backups and rollback scripts: running again never produces a duplicate slip, invoice or commission.

  • Checked against what users already trust

    Every new figure is compared with a report or standard field the team already uses before it goes to validation.

  • Process first, then code

    Before customizing, I check whether the ERP process already handles it. Sometimes the problem is in the entry, not the query.

  • Errors that explain themselves

    When setup is missing or there is nothing to process, the message says why and where to fix it.

  • Business decisions belong to the client

    Open questions become a decision list with a technical proposal, and every delivery ships with documentation for the people who run it.
