Cómo trabajo

Prácticas que se repiten en todas las entregas.

  • El sistema estándar queda intacto

    Todo objeto nuevo lleva el prefijo AD_ y los campos se crean por el diccionario de datos. Las actualizaciones del ERP no rompen nada.

  • Reprocesar es seguro

    Claves de rastreo, verificación previa, respaldo y script de rollback: volver a ejecutar nunca genera guía, factura o comisión en doble.

  • Verificado contra lo que el usuario ya confía

    Cada número nuevo se compara con un informe o campo nativo que el equipo ya usa antes de ir a validación.

  • Primero el proceso, después el código

    Antes de personalizar, verifico si el proceso del ERP ya lo resuelve. A veces el error está en el registro, no en la consulta.

  • Errores que se explican

    Cuando falta un registro o no hay nada que procesar, el mensaje dice el motivo y dónde corregir.

  • Las decisiones de negocio son del cliente

    Los puntos abiertos se convierten en una lista de definiciones con propuesta técnica, y cada entrega sale con documentación para quien opera.
